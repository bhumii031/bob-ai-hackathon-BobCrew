## 🚀 Project Overview

**Sentinel** is a fully client-side pharmacovigilance and regulatory intelligence web application built for the **IBM Bob AI Hackathon** (Track: AI / Healthcare & Life Sciences).

It solves two of the biggest pain points in drug safety and regulatory affairs:

1. **Signal Detection** — automatically runs PRR, ROR, Chi-square disproportionality analysis on uploaded adverse event CSV data and flags drug–event safety signals (Critical / Signal / Watch / No Signal).
2. **Submission Readiness** — fuzzy-matches a dossier table-of-contents against the full ICH M4 CTD reference structure and surfaces gaps with Critical / High / Medium severity ratings.

> Built entirely using **IBM Bob** in Agent Mode — every component, algorithm, and style was generated by the IBM Bob AI assistant.

---

## 🎯 Problem Statement

Pharmacovigilance teams must manually sift through thousands of spontaneous adverse event reports to detect drug safety signals — a slow, error-prone process requiring specialist statistical expertise. Simultaneously, regulatory dossier managers preparing NDA/MAA submissions must cross-check documents against the complex ICH M4 CTD structure by hand, often missing critical gaps that lead to costly regulatory rejections or major objections from authorities.

---

## 💡 Solution

Sentinel runs validated disproportionality algorithms directly in the browser on uploaded CSV datasets to surface drug–event safety signals in seconds — no backend required. It also performs Levenshtein fuzzy-match gap analysis of a user's dossier TOC against the complete ICH M4 CTD reference, scoring readiness per module and flagging gaps before submission.

## ✨ Key Features

| # | Feature | Description |
|---|---------|-------------|
| 1 | **Signal Detection Engine** | PRR, ROR, Chi-square (Yates), 95% CI — signals ranked Critical / Signal / Watch / No Signal |

| 3 | **ICH M4 CTD Gap Analysis** | Fuzzy matching against 60-item CTD reference; per-module readiness scores & submission risk |
| 4 | **Interactive Visualisations** | Scatter plots, trend line charts, bar charts, animated SVG readiness gauge (Recharts) |
| 5 | **Dark Mode + Responsive UI** | Full dark/light toggle; Tailwind CSS responsive layout with custom sidebar navigation |
| 6 | **Zero Backend / Privacy-First** | All computation runs in-browser — no API calls, no data leaves the user's machine |

### Prerequisites
- Node.js 18 or higher
- npm 9 or higher

### 1. Clone the Repository
```bash
git clone https://github.com/bhumii031/bob-ai-hackathon-BobCrew.git
cd bob-ai-hackathon-BobCrew
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment
No `.env` file is required. The app is fully client-side with built-in sample data — open and run immediately.

### 4. Run the Project
```bash
npm run dev
```
Opens at **http://localhost:5173** with sample data pre-loaded.

### Production Build
```bash
npm run build
npm run preview
```

## 📥 Input Formats

### Adverse Events CSV (Signal Detection)

The CSV **must** contain these 7 columns (case-sensitive):

| Column | Type | Description |
|--------|------|-------------|
| `drug_name` | string | Name of the drug |
| `adverse_event` | string | Adverse event term |
| `patient_age` | integer | Patient age |
| `patient_sex` | string | `M` or `F` |
| `report_date` | date | Format: `YYYY-MM-DD` |
| `outcome` | string | `serious`, `non-serious`, or `death` |
| `reporter_type` | string | e.g. `Physician`, `Pharmacist`, `Patient` |

**Example:**
```csv
drug_name,adverse_event,patient_age,patient_sex,report_date,outcome,reporter_type
Vexarinib,Hepatotoxicity,54,F,2022-03-15,serious,Physician
```

### Dossier TOC (Submission Readiness)
Plain text (`.txt`) file or paste — one section title per line. The fuzzy matcher tolerates minor wording differences.

## ⚠️ Known Limitations

- No user authentication — single-user browser tool, not production-hardened for multi-user environments
- CSV files > 50,000 rows are capped at the first 50K rows to maintain browser responsiveness
- JS bundle is ~644 KB (uncompressed) due to Recharts + D3 — code-splitting not applied in this version
- CTD gap detection uses Levenshtein fuzzy matching, not NLP — highly abbreviated TOC formats may yield lower accuracy
- No persistent storage — uploaded data resets on page refresh (no IndexedDB / localStorage yet)

## 🏅 What We're Most Proud Of

- **End-to-end PV math in pure JavaScript** — PRR, ROR, Yates-corrected Chi-square, and log-normal 95% CI implemented from scratch with no external stats library

- **Severity-weighted signal scoring** — outcome weighting (death=3, serious=2, non-serious=1) elevates fatal events to Critical Signal, matching real-world PV practice
- **Production-quality UI in a hackathon timeframe** — dark mode, animated SVG gauge, sortable/filterable tables, scatter plots, trend charts — all cohesive and accessible
- **Built entirely with IBM Bob** — every line of code generated by IBM Bob Agent Mode, demonstrating its capability for domain-expert-level life sciences applications
